# Loan Risk Predictor

A machine learning project for predicting loan default risk using structured lending data.

## Objectives

- Explore risk drivers in lending portfolios
- Train and evaluate ML models for default prediction
- Provide a transparent model card and evaluation summary

## Repository structure

- `data/` – Dataset description and access notes
- `notebooks/` – EDA and model development notebooks
- `src/` – Reusable training and inference code
- `evaluation/` – Metrics and model comparison
- `model-card.md` – Model documentation and limitations

## Target audience

- Data scientists and ML engineers  
- Risk and analytics teams  
- Lending product owners
